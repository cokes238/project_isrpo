# MovieTracker

## МОПСЯТРЯСКА, ТРЯСИ МОПСЯРКАМИ!!

Веб-приложение для отслеживания фильмов с возможностью фильтрации по жанрам.

## Стек технологий

- **Backend:** ASP.NET Core Web API (.NET 8)
- **База данных:** SQLite (Entity Framework Core)
- **Frontend:** HTML, CSS, JavaScript (Vanilla)

## Структура проекта

```
proekt-isrpo/
├── frontend/
│   ├── index.html
│   ├── css/
│   │   └── style.css
│   └── js/
│       ├── api.js
│       └── app.js
└── MovieTrackerApi/
    ├── Controllers/
    ├── Data/
    ├── Helpers/
    ├── Models/
    ├── Repositories/
    └── Program.cs
```

## Запуск

1. Перейти в папку `MovieTrackerApi`
2. Выполнить `dotnet run`
3. Открыть `frontend/index.html` в браузере
